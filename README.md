## Project goal
Clean and analyze customer reviews of women's clothing using Python. This project includes missing-value handling, duplicate checks, data type validation, outlier screening, eight visualizations, and a short insights report.

## Project files
- `dataset/` — original Kaggle CSV should be placed here
- `notebooks/Womens_Clothing_Reviews_Analysis.ipynb` — runnable notebook
- `src/analyze_reviews.py` — analysis script
- `graphs/` — generated visualizations
- `reports/data_cleaning_log.md` — cleaning decisions and outlier checks
- `reports/insights_report.md` — findings from the dataset
- `requirements.txt` — dependencies

## Run
Install dependencies with `pip install -r requirements.txt`. Put `Womens Clothing E-Commerce Reviews.csv` inside `dataset/`, then run `python src/analyze_reviews.py`.

## Dataset source
https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews

This is descriptive analysis of this dataset, not causal analysis or a representative survey of all shoppers.
